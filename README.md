# Rise — dough planner

Plan pizza and bread doughs around when you want to eat: 17 doughs, instant yeast or sourdough starter, same-day or overnight timing, step-by-step kitchen mode.

**Use it:** https://mikemccoywinnipeg-maker.github.io/Rise-Bread-Dough-Calculator/

On iPhone, open the link in Safari, then Share → Add to Home Screen. After the first visit it works offline.
